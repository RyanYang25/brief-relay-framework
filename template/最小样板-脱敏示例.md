# 最小样板 · 脱敏对照示例（v1.13 发布物）

> 这是一份**已填好、全部脱敏**的最小完整 BRF 实例，供新使用者"照填对照"——空白 starter（`BRIEF.md`）给骨架，本示例给"填完长什么样"。
> 铁律：**真实值只留在本地私有工作区；公开版一律替换为中性占位符；真实值↔占位符的映射表只留在本地，绝不进公开包。**

## 1. 契约头（@context-root，含可选 environment / origin）

```
<!-- @context-root
role: 项目唯一入口 + 演进引擎
produced_by: 更新 SOP（自动/手动触发）
consumed_by: 所有 Agent 与人类接手者，每次会话开头必读
update_trigger: 任何状态/决策/文件结构变更后
last_updated: YYYY-MM-DD
environment: 单机（{ROOT}=本仓库根）；多环境项目填环境拓扑表指针
origin: 续跑自 <上一棒 Agent 副本 / 来源文档>（v1.13 可选，顺序单写者可省）
upstream: context/current.md（活跃状态）、context/standards.md（约束）
downstream: context/current.md → context/standards.md
-->
```

- `environment`（v1.12 可选）：多机/多副本/网络同步项目必填，指向环境拓扑表；单机可省。
- `origin`（v1.13 可选）：标注本次承接从哪来——`续跑自 <来源>` 或 `分叉自 <来源>`；多 Agent 并行（第十九章）或跨副本接力时填，顺序单写者项目可省。

## 2. BRIEF.md 最小填好版（敏感处已占位）

```markdown
# BRIEF.md - 项目简报

> 最后更新：YYYY-MM-DD ｜ 更新人：<姓名/角色> ｜ 更新原因：<一句话说明本次改了什么>

## 一、项目画像（稳定信息）
- **项目名称**：<项目名称>
- **目标**：<一句话说清要达成什么>
- **交付物**：<核心产出是什么>
- **关键约束**：<时间/资源/合规等限制；不写真实内网地址与密钥>

| 角色 | 姓名 | 决策权 |
|------|------|--------|
| 项目负责人 | <姓名> | ⭐⭐⭐ 最高 |
| 执行/顾问 | <姓名> | ⭐ 中 |

## 二、当前状态（一句话 + 指针）
第一版方案完成，待反馈 → 详见 `context/current.md`
```

## 3. current.md 最小片段（演示 origin 续跑与决策留痕）

```markdown
<!-- @context
role: 当前活跃上下文（activeContext）
last_updated: YYYY-MM-DD
origin: 续跑自 <上一棒来源>
-->

## Open 态
| 类型 | 内容 | 背景/来源 | 状态 |
|------|------|----------|------|
| 待验证 | <待验证事项> | <来源> | 未闭合 |

## Decisions 态
| 日期 | 决策内容 | 依据/理由 | 负责人 | 影响范围 |
|------|---------|---------|--------|---------|
| YYYY-MM-DD | <决策> | <为什么这么定> | <姓名> | <影响到哪> |
```

## 4. 脱敏占位对照表（映射表只留本地，不进公开包）

| 类别 | 本地真实值（私有） | 公开版占位 |
|------|------------------|-----------|
| API key / token | `sk-<真实密钥>` | `<API_KEY>` |
| 密码 / 私钥 | `<真实密码/私钥>` | `<SECRET>` |
| 内网 IP / 主机名 | `192.168.x.x` / `<内网主机>` | `<intranet-host>` |
| 共享路径本机账号/机器名 | `\\<本机>\<共享>` | `<share-path>` |
| 个人邮箱 | `<real@example.com>` | `<email>` |
| 手机号 / 住址 | `<真实>` | `<phone>` / `<address>` |
| 本机绝对路径 | `C:\…` / `E:\…` | 逻辑路径 `{ROOT}/…`（见 12.5） |

> 发布前按 15.3「发布前脱敏核对」逐项过：凭证 / 内网标识 / 个人隐私 / 裸绝对路径；历史文档按 12.5 保留原文 + 注记，不在公开版静默改写。
